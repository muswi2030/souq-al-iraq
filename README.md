# 🛒 سوق العراق — Souq Iraq

منصة إعلانات مبوّبة للبيع والشراء في العراق. تعمل بلا خادم، مدعومة بـ Firebase.

---

## ✨ المزايا

- 📸 نشر إعلانات مع حتى 5 صور
- 💬 مجموعات محادثة سحابية فورية
- 🔨 مزاد مصغر على السلع
- ⭐ نظام تقييمات للبائعين
- 💾 يعمل بلا اتصال (PWA)
- 🌙 وضع داكن
- 🔍 بحث صوتي
- 🗺️ خريطة تفاعلية للإعلانات

---

## 🛠️ التقنيات

| الطبقة | التقنية |
|--------|---------|
| الواجهة | HTML + CSS + Vanilla JavaScript |
| قاعدة البيانات | Firebase Firestore |
| المصادقة | Firebase Auth (Anonymous + Email) |
| PWA | Service Worker + Web Manifest |

---
